# Oscuro website

The generated website for **Oscuro**, free firmware for M-Vave keyboards: https://kartun83.github.io/oscuro-firmware/

This repository only serves the site (the `gh-pages` branch, built from the project's source, which lives elsewhere). There is nothing to build here.
