Install

Put Oscuro on your SMK-37.

A few minutes in a browser. Every update can be undone, and M-Vave's own firmware goes back any time.

The package link will appear here once the first release is published.

What you need

  • A computer with Chrome or Edge, which can talk to MIDI devices.
  • The USB cable that came with the keyboard.
  • The Oscuro package, with the installer page and the app file of the build you choose.
  • For a first install: M-Vave's own firmware file for your model, from M-Vave's download page. It is not provided here. M-Vave's download page

Install or update

  1. 1

    Prepare

    Close your DAW and any other MIDI app. Connect the keyboard and open the installer page from the package.

  2. 2

    Choose the files

    Under Install or update Oscuro, choose the Oscuro file for the build you want. On a first install, while the keyboard still runs M-Vave's firmware, also choose M-Vave's firmware file. The page combines the two on your computer. If the keyboard already runs Oscuro, the Oscuro file alone is enough.

  3. 3

    Install

    Press Install Oscuro and keep the cable connected until the page says Finished. The keyboard restarts on its own.

Compare the builds →

Which build?

The flavour table on the home page says what each build is for and what it gives up.

Test builds

Until a public release, every build is a test build: it carries a little extra diagnostics and is labelled as such. Test builds can be undone like any other.

Going back

Under Back to M-Vave's firmware, choose M-Vave's firmware file and press Install M-Vave firmware. It works from Oscuro and from any M-Vave version. If you erased the patch memory, restore your backup first.

Patch memory backup

Oscuro's synth builds keep their patches in the keyboard's user memory, where M-Vave's firmware keeps its own data. Oscuro never erases that data by itself: on the installer's Patch memory tab you can save a backup, erase for patches, and restore the backup later.

Easy to try. Easy to undo.

Only the app is written

The keyboard's boot code, your settings and its calibration stay exactly as they are.

Back to M-Vave in minutes

The installer puts M-Vave's own firmware back at any time, from Oscuro or from any M-Vave version.

Your data is not touched

Oscuro never erases M-Vave's user data by itself. Save a backup of the patch memory first and restore it later.

A safe start

Hold Globe while switching on to skip Bluetooth, the faster clock and other optional extras.
