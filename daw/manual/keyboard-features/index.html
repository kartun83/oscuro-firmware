DAW manual · The keyboard's own features

Scale, Chord, Arp, Note Repeat, sequencer, clock

The DAW builds keep the keyboard's own performance features. They work the same in a DAW session: they change the notes the keys and pads send, and the DAW records the result.

How the buttons work

Most of these buttons share one pattern: tap opens the list, hold switches the mode on or off. In a list, K1 picks a row, K2 changes it, K3 pages, Left goes back. While a list is open it has the knobs and Left / Right; the DAW gets them back when it closes.

Scale

Tap SCALE: K1 Base, K2 Scale, K3 Fix, K4 Shift. Hold SCALE to switch it on or off. With it on, the keys are pulled into the scale; Fix decides what a key outside it does (Down, Up, Near, or Filter it out). Make your own User 1-4 scales by tapping keys on the SCALE list. The Harmony Helper uses the same scale.

Chord

Tap CHORD: Chord (Maj, Min, Dim, Aug), Type (Triad to 13th), Voicing (Fixed or in the Scale). Hold CHORD to switch it on or off. With it on, each key plays a whole chord.

Arpeggiator

Tap ARP for its list; hold it for 0.6 s to switch it on or off. Its sections, reached with Left / Right: ARP, RHYTHM (Euclidean), EVOLVE, STRUM, HUMAN. Hold ARP and turn K1-K8 to edit without opening the list (the knobs are the keyboard's while you hold it).

Note Repeat

Hold NOTE REPEAT and turn K1-K5 (Gate, Swing, Tempo, Rate, Latch); tap it to switch on or off. Pads then repeat while held, for drum rolls into the DAW.

Step sequencer

Seq1, Seq2 (melodic) and Drum (14 lanes), each with 8 patterns of up to 64 steps. In a DAW session SEQ, SEQ PLAY and SEQ REC belong to the DAW. To use the sequencer from SEQ, give SEQ back to the keyboard in the script's settings (see When the keyboard's own pages take over). Projects are kept in memory only and are lost at restart. The sequencer has not been run on a unit yet.

Tempo and clock

All timed features (arpeggiator, Note Repeat, sequencer, Harmony replay and bass pattern) run from one clock.

  • The keyboard leads (Globe → MIDI → Clock: Internal): its own tempo. In a DAW session Oct- + K8 sets the DAW's tempo instead (see Controls that work in every view); set the keyboard's own tempo on the ARP or NOTE REPEAT page.
  • The DAW leads (Clock: USB or Auto): send MIDI clock from the DAW to the keyboard's port (Live: Sync on for the keyboard's output port; FL Studio: Send master sync on the keyboard's output in MIDI settings), and the arpeggiator and the rest follow the DAW's tempo, start and stop. The status bar shows E and the tempo while it follows. Over Bluetooth use Clock: BLE; the tempo settles after about four beats.
  • TAP, where a preset binds it, taps the DAW's tempo while the script is connected.
