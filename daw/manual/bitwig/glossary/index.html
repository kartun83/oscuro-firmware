WordMeaning
AccentThe screen's highlight colour for the session (Bitwig orange, Live amber or FL Studio green by default). It never follows the selected track
AnchorIn the Harmony Helper: the chord the suggestions stay around, played by pad 13
App slotThe area of the keyboard's flash that holds the firmware. Images larger than M-Vave's slot grow it when installed
Bank A / bank BTwo layers of the same controls: K1-K8 / K9-K16, faders 1-4 / their second set, pads (bank A notes, bank B tracks)
BrowserThe view that drives the DAW's browser from the knobs
DAW build / DAW BT buildThe Oscuro firmware made for controlling a DAW; BT adds Bluetooth MIDI
DAW portWith USB Ports: Split, the USB MIDI port that carries the DAW protocol
DAW protocolThe Oscuro messages between the keyboard and the script: what you touch, what the screen and lights show
Device padsPad bank B as the selected device's on/off switches, in the Device view
Drum padsPad bank B as the eight drum sounds of a Drum Machine, in the Device view
Device viewThe view where the knobs are the selected device's remote controls
Fader windowThe four tracks faders 1-4 control, marked F1-F4 in the Mixer
Fine stepsKnob steps eight times smaller, while Oct- or the Shift pad is held
GoldenA reference screen image from the keyboard's UI simulator; the screens in this manual
Key laneThe steps page for one key of a melodic track (Shift pad + Right in the Device view)
Mixer viewEight track strips with volumes, meters and mute / solo / arm
Modulation tickThe mark on a knob arc where modulation moves the parameter right now
Oct- modifierOct- held together with another control; it then never shifts the octave
OverviewThe view with tempo, position, transport states and the project remote controls
Project remote controlsBitwig's eight macros for the whole project
Remote controls / remote pageBitwig's sets of eight device parameters chosen to be played together
ScriptThe Oscuro script for your DAW: SMK-37 Oscuro (Bitwig controller extension), SMK37_Oscuro (Live Remote Script) or SMK-37 Oscuro (FL Studio MIDI script)
SessionThe time the script and the keyboard are connected. It ends two seconds after the link goes quiet
Shift padA pad you made a Shift key in Globe → Physical Controls → Pads
Soft takeoverA fader waits until it passes the current value before it changes it
Split / OneUSB Ports: three MIDI ports (Keys, Pads, DAW) or one
Steps pageThe sixteen pads as sixteen sixteenth-note steps of one drum sound in the clip
Stock firmware / stock scriptM-Vave's own firmware and the DAW script made for it
Touch (automation)Bitwig's automation mode that writes only while a control is touched; turning a knob touches its parameter
Track colourThe selected track's colour in the DAW, shown as a bar or line, never as the accent
Track remote controlsBitwig's eight macros on a track (Bitwig 5+), on K9-K16 in the Device view
ViewOne of the screen's layouts: Device, Mixer, Overview, Browser
