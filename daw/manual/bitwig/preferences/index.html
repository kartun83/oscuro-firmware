16 Script preferences

The SMK-37 Oscuro script has six settings in Bitwig's Settings → Controllers, in the SMK-37 Oscuro panel. A change applies at once: the script hands the keyboard the new setup without a reconnect.

PreferenceChoicesWhat it changes
SEQ buttonScreen views (default), Firmware sequencerScreen views: SEQ cycles Device, Mixer and Overview, and a hold opens the Browser. Firmware sequencer: SEQ stays the keyboard's and opens its sequencer pages; the screen stays in the Device view. SEQ PLAY and SEQ REC drive Bitwig either way
Show modulationYes (default), NoThe tick on a knob arc where modulation moves the parameter
Accent colourBitwig orange (default), Keyboard settingThe screen's highlight colour for the session. Keyboard setting keeps the accent chosen in Globe → System → Accent. The track colour never replaces it
Fader pick-upSoft takeover (default), JumpSoft takeover: a fader waits until it passes the current value (F1^ / F1v show the way). Jump: the value jumps to the fader at once
Knob stepsNormal (128) (default), Fine (256)Clicks for a parameter's full range. Holding Oct- or the Shift pad gives 1024 either way
ConnectionUSB (default), BluetoothHow much the script sends to the keyboard each tenth of a second (about 300 or 120 bytes). Set Bluetooth when the script uses the BLE ports. Names come first, then values, then modulation ticks, so the screen stays readable; a knob you turn still updates at once

Which to change first

  • If you use the keyboard's step sequencer a lot, set SEQ button to Firmware sequencer.
  • If parameter jumps are a problem live (for example on a master volume), keep Soft takeover. If you set levels from scratch each time, Jump is quicker.
  • If you find the knobs coarse for filter sweeps, try Fine (256).
  • Over Bluetooth, set Connection to Bluetooth.
