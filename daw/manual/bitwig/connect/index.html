USB: one port or three

By default the keyboard shows up as one USB MIDI port, SMK-37 Oscuro USB. Keys, pads and the DAW link share it, and the script sorts them out. This is the simplest setup and works out of the box.

For separate recording of keys and pads, set Globe → DAW & USB → USB Ports → Split and restart the keyboard. It then shows up as three ports:

PortCarriesIn Bitwig
Keyskeys, knobs and faders outside a script, wheels, arpeggiator, melodic sequencer tracksadd as a generic MIDI keyboard
Padspads (and the Harmony Helper's chords), Note Repeat, the drum trackadd as a second generic MIDI keyboard
DAWthe Oscuro DAW protocolthe input and output of the SMK-37 Oscuro script

With Split, record the keys on one instrument track and the pads (drums, Harmony chords) on another, as if they were two instruments.

Bluetooth MIDI (DAW BT)

  1. Tap BT. The first start shows Starting Bluetooth…; the screen then says On (advertising).
  2. Pair SMK-37 Oscuro BLE in your computer's MIDI setup. On a Mac: Audio MIDI Setup → Window → Show MIDI Studio → Bluetooth, then Connect.
  3. In Bitwig, choose SMK-37 Oscuro BLE as the script's input and output, and set the script preference Connection to Bluetooth.

The whole DAW session runs over Bluetooth: screens, knobs, pads and transport. The keyboard needs no USB cable at all, so it can run from a power bank. It uses one link at a time: the one the DAW connected on last; traffic for the script on the other link is ignored while it lasts.

Things to know:

  • Bluetooth carries one MIDI stream. Keys and pads are told apart by MIDI channel (pads on channel 10 by default); there is no Split.
  • If BT is left on, it starts by itself after power-on. Hold Globe while switching on to skip it for that start.
  • Bluetooth adds a little delay, and the screen updates arrive in small bursts. See Troubleshooting if it feels slow.
  • Bluetooth MIDI has been tried with a Mac only; Windows, iOS and Android are untested. The DAW session over Bluetooth is tested on a computer only, not yet with a keyboard.
