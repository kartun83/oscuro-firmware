4 Set up Bitwig Studio

The SMK-37 Oscuro script is a Bitwig controller extension in the folder bitwig/SMK37-Oscuro of the DAW package. You copy it once into Bitwig's script folder and add it as a controller.

Needs Bitwig Studio 6.1 or newer. Older versions are not supported: Bitwig shows SMK-37 Oscuro needs Bitwig Studio 6.1 or newer and the script does not start.

Install the script

Copy the folder SMK37-Oscuro (without its tests folder) into Bitwig's Controller Scripts folder:

SystemFolder
macOS~/Documents/Bitwig Studio/Controller Scripts/
Windows%USERPROFILE%\Documents\Bitwig Studio\Controller Scripts\
Linux~/Bitwig Studio/Controller Scripts/

When you update Oscuro, replace the folder with the one from the new package.

Add the controller

  1. In Bitwig open Settings → Controllers.
  2. Add controller, choose the vendor Oscuro and the model SMK-37 Oscuro.
  3. Set its MIDI input and output: - USB Ports: One → SMK-37 Oscuro USB for both. - USB Ports: Split → the DAW port for both, then add the Keys and Pads ports as two Generic → MIDI Keyboard controllers. - Bluetooth → SMK-37 Oscuro BLE for both.
  4. Bitwig may find the keyboard by itself when it is connected; check the ports anyway.

When the script reaches the keyboard, the screen turns to the Device view with the selected device's knobs. If the keyboard is not connected yet, the script waits and connects as soon as it is.

Keep M-Vave's stock script

M-Vave's own Bitwig script (SMK37-Elite, from M-Vave's repository) speaks to the stock firmware. Keep it installed if you ever go back:

  • On Oscuro, enable SMK-37 Oscuro and disable or remove the stock controller in Settings → Controllers.
  • On M-Vave's firmware, do the opposite. The Oscuro script never sends anything the stock firmware would act on; it just waits.

Both scripts can sit in the Controller Scripts folder at the same time. Only one should be active on the keyboard's port.

Help inside Bitwig

The script folder holds a short help page, SMK37-Oscuro.html (setup and the quick-reference card), and this manual as oscuro-bitwig-manual.pdf. Bitwig shows a page named after a script as that controller's help, as it does for its own scripts; whether it does so for scripts in your own Controller Scripts folder has not been confirmed yet. If no help link appears, open the two files from the folder yourself.

Preferences

The script's settings sit in the controller's panel in Settings → Controllers. The defaults suit most people; each is explained in Script preferences:

PreferenceDefault
SEQ buttonScreen views
Show modulationYes
Accent colourBitwig orange
Fader pick-upSoft takeover
Knob stepsNormal (128)
ConnectionUSB (set Bluetooth on the BLE ports)
