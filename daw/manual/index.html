DAW manual

The Oscuro DAW manual

Everything the DAW and DAW BT builds do with Bitwig Studio, Ableton Live and FL Studio: how to connect, what every key does in each view, and how to work with it. One book per DAW.

Download the Bitwig PDF PDF, 0.5 MB Download the Live PDF PDF, 0.5 MB Download the FL Studio PDF PDF, 0.4 MB

Two books

  • Oscuro for Bitwig Studio
  • Oscuro for Ableton Live
  • Oscuro for FL Studio

Oscuro for Bitwig Studio

The manual for the DAW and DAW BT builds on the M-Vave SMK-37 Elite with the SMK-37 Oscuro script for Bitwig Studio

Oscuro for Ableton Live

The manual for the DAW and DAW BT builds on the M-Vave SMK-37 Elite with the SMK37_Oscuro Remote Script for Ableton Live

Oscuro for FL Studio

The manual for the DAW and DAW BT builds on the M-Vave SMK-37 Elite and SMK-37 Pro with the SMK-37 Oscuro script for FL Studio

The chapters about the keyboard itself are the same in both books; setup, views, workflows and reference are written for each DAW.
