The screen never changes to the Device view

  1. Read FL's hint bar and View → Script output. Oscuro firmware not found on this port: the wrong port is chosen, or the keyboard runs other firmware. This SMK-37 Pro (or Elite) runs M-Vave firmware: install Oscuro, or use M-Vave's script. Set the output port number: see step 3.
  2. Is Oscuro running? Tap Globe → About: it should show DAW.
  3. Are both directions set up? Options → MIDI settings: the keyboard's port in Input with SMK-37 Oscuro and a Port number, and the same port in Output with the same Port number.
  4. Is the folder in the right place? The .py files must sit directly in Settings/Hardware/SMK37_Oscuro/. If SMK-37 Oscuro is missing from the Controller type list, the folder is in the wrong place or nested one level too deep.
  5. Is another app holding the port? Close the web installer, the preset editor and MIDI Suite.
  6. Choose another controller type and SMK-37 Oscuro again, or replug the cable.

The screen says Host lost

The keyboard got more data than its MIDI input could take, or the link was quiet too long. Lower flush_budget in oscfl_settings.py (Bluetooth especially) and reload the script.

Knobs, pads or SEQ do the wrong thing

  • Two scripts on one port. M-Vave's script on the same port reacts too; give that port one controller type only.
  • A keyboard page is open. Close Globe settings, a SCALE / ARP / CHORD list or the Harmony Helper.
  • The pads play notes instead of steps. Press Knob Bank and Fader Bank together for bank B.
  • The pads are in another mode. Hold the Shift pad to see which; Oct- + pad 9 goes back to Steps.
  • Perform stays dark. Performance mode is off in the playlist.
  • SEQ opens the sequencer. seq_views is False.

A fader does nothing

Soft takeover: move it toward the arrow (F2^ up, F2v down), or set soft_takeover to False.

Keys play twice, or not at all

Pad bank A and the keys play the selected channel through FL's normal MIDI input. With Split, the Keys and Pads ports must be enabled as inputs. If the same notes also reach FL through another input, they play twice.

A preset loads the wrong one

FL does not say which preset is loaded, so the script counts from the last one it loaded (Browser). Load one from the keyboard once and it counts right from then on.

The keyboard restarted, or the cable came out

The script starts a new session by itself when the keyboard answers again. If the screen stays on the keyboard's own view, reload the script.
