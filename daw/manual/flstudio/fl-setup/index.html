4 Set up FL Studio

The SMK-37 Oscuro script is an FL Studio MIDI script in the folder flstudio/SMK37_Oscuro of the DAW package. You copy it once into FL's Hardware folder and choose it for the keyboard's port. It works the same on the SMK-37 Elite and the SMK-37 Pro.

Written for FL Studio 2026. An older FL Studio loses the parts its scripting interface lacks (following a focused effect window, cloning patterns, the browser): the script skips them and says so on the keyboard.

Install the script

  1. Quit FL Studio.
  2. Copy the folder SMK37_Oscuro (without its tests folder) into FL's Hardware folder:
SystemFolder
macOS~/Documents/Image-Line/FL Studio/Settings/Hardware/
Windows%USERPROFILE%\Documents\Image-Line\FL Studio\Settings\Hardware\

If you moved FL's user data folder, use the one FL shows under Options → File settings. The .py files must sit directly in Hardware/SMK37_Oscuro/.

When you update Oscuro, replace the folder with the one from the new package. Keep your oscfl_settings.py if you changed it (see Script settings).

Choose it for the keyboard's port

  1. Start FL Studio and open Options → MIDI settings.
  2. In the Input list, select the keyboard's port and enable it: - USB Ports: One → the keyboard's only port, SMK-37 Oscuro USB. - USB Ports: Split → the keyboard's third port, the DAW port. - Bluetooth → SMK-37 Oscuro BLE.
  3. Set its Controller type to SMK-37 Oscuro (FL usually picks it by itself) and give it a Port number, for example 10.
  4. In the Output list, select the same port and give it the same Port number. This is how the script reaches the keyboard's screen and lights; without it the keyboard stays on its own screen.
  5. With Split: enable the Keys and Pads ports as inputs too, with (generic controller). They play the selected channel.

When the script reaches the keyboard, the screen turns to the Device view. If the keyboard runs other firmware, FL's hint bar says so after a few seconds and the script waits.

SMK-37 Elite and SMK-37 Pro

Both keyboards run the same Oscuro firmware, show the same ports and have the same controls, so everything in this manual applies to both. If the keyboard still runs M-Vave's firmware, the hint bar names it (this SMK-37 Pro runs M-Vave firmware): install Oscuro, or use M-Vave's own FL script for that keyboard.

Keep M-Vave's script

M-Vave's FL script for the stock firmware speaks a different language. This one has its own name, so both can be installed. Choose SMK-37 Oscuro while the keyboard runs Oscuro.

The manual next to the script

FL has no help page for scripts. The DAW package puts this manual, oscuro-flstudio-manual.pdf, next to the SMK37_Oscuro folder.

Settings

FL has no settings panel for scripts. The script's settings are in oscfl_settings.py in its folder; see Script settings.
