Plugin presets

The list shows the plugin's own presets by name. Turn K1 to move the cursor (K2 by eight) and press Right to load; Left closes. The preset the script loaded last is marked \*.

FL can only step a plugin's presets forward and back and does not say which one is loaded, so the script counts from the last preset it loaded, starting at the first. If you changed the preset with the mouse, the first load from the keyboard can land off by that difference; load once, and the count is right from then on.

A plugin without presets opens FL's browser instead (No presets for … : FL browser).

FL's browser

FL's browser opens and K1 moves its cursor; the screen lists the names the cursor has passed (FL gives no list of what is ahead, so the list grows as you scroll).
