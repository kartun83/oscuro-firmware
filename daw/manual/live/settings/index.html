18 Script settings

Live has no preference panel for Remote Scripts, so the SMK37_Oscuro settings live in a small file, user_settings.py, in the script's folder. Open it in any text editor, change a value, save, and re-select the control surface in Settings → Link, Tempo & MIDI (or restart Live).

SettingValuesWhat it changes
seq_viewsTrue (default), FalseTrue: SEQ cycles Device, Mixer and Overview, and a hold opens the Browser. False: SEQ stays the keyboard's own sequencer button; the screen stays in the Device view
soft_takeoverTrue (default), FalseTrue: a fader waits until it passes the current value. False: the value jumps to the fader
accent'live' (default), 'off''live': the screen's accent is the script's amber for the session. 'off': the accent set in Globe → System → Accent
fineFalse (default), TrueTrue: 256 knob steps per range instead of 128. Holding Oct- or the Shift pad always gives 1024
flush_budget300 (default)Bytes the script sends to the keyboard per pass. The keyboard's MIDI input is small; a flood makes it report Host lost. Raise it only if the screen lags, lower it over Bluetooth if the link drops

Keep the quotes around 'live' and 'off', and the capital letters of True and False. A copy of your changed file is worth keeping: an update of the script folder replaces it.
