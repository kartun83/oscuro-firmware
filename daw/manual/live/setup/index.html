4 Set up Ableton Live

The SMK37_Oscuro script is a Live Remote Script in the folder ableton/SMK37_Oscuro of the DAW package. You copy it once into your User Library and choose it as a control surface. It needs Live 12 or newer.

Needs Live 12 or newer. Older versions are not supported: Live's status bar says SMK37 Oscuro needs Live 12 or newer and the script does nothing.

Install the script

  1. Quit Live.
  2. Copy the folder SMK37_Oscuro (without its tests folder) into the Remote Scripts folder of your User Library:
SystemFolder
macOS~/Music/Ableton/User Library/Remote Scripts/
Windows%USERPROFILE%\Documents\Ableton\User Library\Remote Scripts\

Create Remote Scripts if it is missing. If your User Library is somewhere else, use the folder Live shows under Settings → Library. The .py files must sit directly in Remote Scripts/SMK37_Oscuro/.

When you update Oscuro, replace the folder with the one from the new package. Keep your user_settings.py if you changed it (see Script settings).

Choose it as a control surface

  1. Start Live and open Settings → Link, Tempo & MIDI.
  2. In a free Control Surface row choose SMK37_Oscuro, and set its Input and Output: - USB Ports: One → the keyboard's only port, SMK-37 Oscuro USB. - USB Ports: Split → the keyboard's third port, the DAW port. - Bluetooth → SMK-37 Oscuro BLE.
  3. In the MIDI port list below, set the keyboard's Keys and Pads ports (or its only port) to Track: On, so they play notes, and Remote: Off. Leave Sync off unless you want the keyboard to follow Live's clock (see Scale, Chord, Arp, Note Repeat, sequencer, clock).

When the script reaches the keyboard, the screen turns to the Device view. If the keyboard runs other firmware, Live's status bar says Oscuro firmware not found and the script waits.

Keep the stock-firmware script

A script made for M-Vave's stock firmware speaks a different language. This one has its own name, so both can be installed. Use SMK37_Oscuro while the keyboard runs Oscuro, and the stock-firmware script when it runs M-Vave's firmware. Only one of them should be a control surface on the keyboard's port.

The manual next to the script

Live has no help page for Remote Scripts. The DAW package puts this manual, oscuro-live-manual.pdf, next to the SMK37_Oscuro folder: keep it there, or anywhere you can find it.

Settings

Live has no preference panel for Remote Scripts. The script's settings are in user_settings.py in its folder; see Script settings.
