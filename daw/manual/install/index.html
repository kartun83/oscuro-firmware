DAW manual · Getting started

Install, update, go back

The web installer writes Oscuro to the keyboard over the USB cable and can put M-Vave's own firmware back whenever you want. It runs in Chrome or Edge on your computer; nothing needs installing.

What you need

  • Chrome or Edge (they have Web MIDI), the USB cable and the Oscuro package (oscuro-installer.html and the …-daw_bt-app.bin or …-daw-app.bin file).
  • For the first install: M-Vave's firmware file for your keyboard, for example SMK-37 Elite_016.fwsc from M-Vave's download page. The package does not contain it.

Install or update

  1. Close your DAW and any other MIDI app. The installer needs the keyboard's MIDI port to itself.
  2. Connect the keyboard and open oscuro-installer.html.
  3. Under Install or update Oscuro, choose the app file: …-daw_bt-app.bin for Bluetooth, …-daw-app.bin without.
  4. First install only (the keyboard still runs M-Vave's firmware): also choose M-Vave's .fwsc file. The page combines the two on your computer.
  5. Press Install Oscuro and keep the cable in until the page says Finished. The keyboard restarts by itself.

Check the version afterwards: tap Globe, turn K1 to About and press Right. The About screen shows the version and DAW, with TEST in a test build. The DAW script also receives the version when it connects.

Images larger than M-Vave's app slot

The keyboard keeps its firmware in an area of fixed size, the app slot. The DAW BT image is about 81 KB larger than M-Vave's slot. The package's README.md names every app file that is too large (more than 621,320 bytes).

  • The web installer (0.83.2 and newer) takes such a file. Choose it together with your M-Vave .fwsc file under Install; the installer moves the keyboard's settings area behind the app to make room.
  • What this costs: the area where M-Vave's firmware kept its own settings is overwritten.
  • From a keyboard that still runs M-Vave's firmware, M-Vave's firmware does the writing, and it has not yet been tried with a grown image. If it refuses, nothing is changed.
  • Once the slot is grown it stays grown, and later updates install as usual.

Go back to M-Vave's firmware

Under Back to M-Vave's firmware, choose M-Vave's .fwsc file and press Install M-Vave firmware. This works from Oscuro and from any M-Vave version. If you made a patch-memory backup (.ksua) before you started using Oscuro, restore it first on the Patch memory tab; it brings M-Vave's user data back.

After going back, use the stock-firmware script for your DAW again. The Oscuro script stays quiet on stock firmware (see Troubleshooting).

Grown slot and going back. Going back to M-Vave's firmware from a keyboard whose slot was grown for an oversize image has not been tried on a unit yet. If anything goes wrong, the recovery route is described in guides/FO1_flash_over.md in the package.
